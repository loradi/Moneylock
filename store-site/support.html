Support

Help with Moneylock, budgets, and Vector.

Getting started

  • Set a weekly, biweekly, or monthly plan and add your category caps.
  • Add purchases manually, with voice entry, or by scanning a receipt.
  • Download the on-device Vector model from Settings before using Vector.
  • Use Settings to export a CSV backup or configure optional private-server sync.

Vector

Vector can help manage Moneylock records, budgets, subscriptions, categories, and savings goals. It asks for confirmation before a saved change. Vector only provides Moneylock help and financial education; it does not provide personalized investment, legal, tax, insurance, or credit advice.

Permissions

Camera, microphone, and speech-recognition permissions are optional. You can continue using Moneylock manually if you choose not to grant them.
